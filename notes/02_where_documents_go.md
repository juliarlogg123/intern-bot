# Where documents go (SurePrep binder / UltraTax input)

| Client document | Where it goes |
|---|---|
| SSA-1099 | The IRS-1099 Social Security Benefit Statement |
| Voided check | General information → Client correspondence (bank info also goes on the client in UltraTax) |
| Prescription / medication purchases | Itemized deductions → Medical and dental expenses |
| Donations / contributions (churches, foundations, endowment funds, etc.) | Cash contributions and carryovers |
| Settlement | Capital gains → Sale of business property |
| WBH invoice | Misc. deduction |
| Car purchase | Misc. deduction |
| Car registration renewal | Property tax |
| 1099-SA and 5498-SA | Form 8889 - Health Savings Account |
| Broker statement (1099 Composite / "CONS") | Broker - 1099 CONS (see UltraTax note for rules) |
| K-1 | Only pull the K-1 from the preparer docs |

## Rules
- Do not pull returns that were not created by WBH.
- Do not pull extensions.
- Any cash contribution: use the date **12/31**.
- If a file shows as "superseded" during review, it was replaced because of duplicates.

If a document isn't on this list, ask Reagan where it goes.

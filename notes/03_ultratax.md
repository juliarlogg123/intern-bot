# UltraTax procedures

## Creating a client in UltraTax
1. Click the **white sheet** next to the folder icon.
2. Type **everything in UPPERCASE except the email address.**
3. Include the routing number and account information from the client's voided check.

## Client not found (SurePrep integration)
- SP → Integration → Select → check the bottom box on the right.

## UltraTax recreation notes (entering a return)
- **Deposit / electronic funds withdrawal:** always select **2** for "taxpayer verified all bank info by".
  - Do this AFTER entering the bank information, because selecting it locks the cells.
- **Contact page:** enter the phone number and email.
- **E-filing ID:** enter the driver's license (DL) information.
  - Method to verify: **2 - remote**.
- **Payments / penalty:** look at the PY (prior-year) return and add the tax and AGI for both the US and state returns.
  - Check the PY return to make sure nothing was applied to next year.
- **W-2:** you do not need the state ID.
- **Broker - 1099 CONS:**
  - Always include the last 4 digits (of the account).
  - Always enter the state.
- **Mortgage interest:** in the description, put the address.
- **Any cash contribution:** date 12/31.
- **Always fill in the state box.**
- When finished: **Edit → Transfer ownership → "Recreation ready for review".**

## PRR report
- Codes **T, S, J** - always put a description.
- Leave **5 spaces** if there's something related to it below.
- Brokerage statement: add lines for the other items (5 spaces).
- Everything in ALL CAPS.
- Do the PRR for **both state and federal.**

## Posting 2025 documents for clients who request them
1. Open the client's Onvio and their 2025 UltraTax.
2. Check which entities are missing documents based on the client's view in Onvio.
3. In UltraTax: hit the **File** button → search by name → open → click the third option and click the option below.
4. Go to the green **Print** icon → drop-down → **Silent**.
   - Cross-check the filing instructions for the US and GA tax returns.
5. Go to **Diagnostics** and run through each diagnostic to make sure there are no issues.
6. **File → Print → Client copy electronic.**
   - Make sure "password protected" is OFF → hit **Assemble**.
7. Red plug icon → **Transmit returns** under Web.
8. Make a new client document folder in their Onvio and share it with the client, with both the source documents and the tax documents.

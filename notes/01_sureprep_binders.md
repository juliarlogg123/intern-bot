# SurePrep binders (1040s): from Jetpack to "Ready for Prep"

## Part 1 - Beginning process

1. **Open Jetpack Workflow.**
   - Go to Jobs → Sort by In Date → drag In Date before Due Date in the sorting bar → filter label for "Ready for SurePrep".
2. **Change the job label to "In Verification".**
   - Check off the tasks completed before this point, such as "Send tax organizer", "Organizer completed", "Engagement letter signed and filed", and "Source documents received" (add the "In date").
   - Assign yourself to tasks 4-8.
3. **Go to Onvio and pull the client's documents.**
   - The first document's file name must match the client ID from Onvio. Use the organizer if available; if not, use their W-2.
   - Make sure NOT to pull any of their extensions.
   - From the preparer docs, only pull their K-1.
   - Do not pull returns that were not created by WBH.
4. **Extract all files from the zip file** and rename the organizer to the client ID.
5. **Open SurePrep** → click the arrow next to "Create new binder" → hover over 1040 → select **"1040 SCAN ORGANIZE"**. On the same bar, to the right, make sure the correct year is selected.
6. **Upload the client-ID file first.** Only open the file you renamed to the client ID number (most likely the organizer or W-2).
   - Once it has uploaded, browse and pull in the rest of the documents you saved in your folder.
   - Confirm the template is for the correct year.
   - Hit Submit and wait for the binder to show up in Verification.

## Part 2 - Verification process

1. In the Verification section, click the **folder icon under Options** to open the binder for verification.
2. Once you have finished verifying the documents, continue forward.
3. Reload SurePrep and search the client ID to find the file. Click the folder icon and double-click the download to open the file.
4. Look through the **non-indexed pages** and try to assign each one to a folder or file in the binder.
   - If a file shows as "superseded", it was replaced because there were duplicates.
5. When done, do a **level 1 check** on the documents.

## Part 3 - Closing out the SurePrep binder

1. After the level 1 check, hit the **Transfer** button (the red and purple arrows) and transfer to the preparer assigned on Jetpack.
   - Change the status to **"Ready for Prep"** in SurePrep.
2. Check off Jetpack steps 4-8.

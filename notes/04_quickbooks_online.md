# QuickBooks Online (QBO) procedures

## Recording a payment
- **Sales & Get Paid → Sales Transactions → New Transaction → Payment.**

## Entering a deposit slip
1. **Create → Bank deposit.**
2. Select each check that belongs to that deposit slip.
3. Make a **new deposit for each slip**, and make sure the totals match the slip.

## Reimbursable expense
- **Create → Check →** use the category for operations (e.g., postage, mailing service).

## When an auto-draft (ACH) fails / payment is returned
1. Go to **Accounting → Bank transactions.**
2. **Create → Expense:**
   - Account: **A/R**
   - Payment method: **ACH**
   - Ref no.: **return pmt**
   - Description, for example: "[Client]'s Q3 dues were returned - the ACH failed"
3. **Match** it to the returned payment in bank transactions.
   - Use the date the returned payment hit QBO.
4. Go to the **customer** and match the invoice to the expense.
   - This will create an open invoice.

## Checking for duplicate bills
- Before entering a vendor bill, search the vendor and check the date and invoice number to make sure it's not a repeat invoice.

For Synovus ACH collections and the related journal entries, see the Synovus note.
